# Business Request

Project:
CRM System

Feature:
Customer Management

Business Goal:
Centralized customer data management.

Problem Statement:
Customer information is currently maintained manually in Excel files by multiple departments.
This causes duplicate records and makes searching customer information difficult.

Users:
- Admin
- Manager

Stakeholders:
- Operations Manager
- Sales Manager

Priority:
High

Current Process:
Admin updates customer data manually in spreadsheets and shares files via email.

Desired Process:
Admin manages all customer data using a centralized application.

Success Criteria:
- Customer creation under 1 minute
- Search results under 5 seconds
- Duplicate records reduced by 80%

Expected Volume:
- Initial customer records: 5,000
- New customers per month: 200

Business Constraints:
- Small team
- VPS 2 CPU / 2 GB RAM
- Must use existing technology stack

In Scope:
- Create Customer
- Update Customer
- Delete Customer
- Search Customer
- Customer Detail

Out Of Scope:
- CRM Analytics
- Marketing Campaigns
- Customer Loyalty Program

Additional Notes:
Internal application only.
