# Documentation Standards

## Purpose

This document defines documentation rules for all artifacts produced by AI Studio.

---

# Documentation Principles

Documentation must be:

```text
Accurate

Consistent

Traceable

Maintainable
```

---

# Required Documents

Every project should contain:

```text
Business Analysis

PRD

UI/UX Design

Technical Design

API Contract

Jira Breakdown

Test Plan

Release Notes
```

---

# Writing Standards

Documents should:

```text
Use Clear Language

Use Consistent Terminology

Avoid Ambiguity

Avoid Assumptions
```

---

# Section Standard

Documents should contain:

```text
Title

Purpose

Scope

Details

Dependencies

Risks

Assumptions
```

---

# Traceability

Every requirement should be traceable.

Example:

```text
Business Requirement
        ↓
PRD
        ↓
User Story
        ↓
API Contract
        ↓
Code
        ↓
Test Case
```


# Golden Rule

Documentation should allow the next agent to continue work without assumptions.
